# SwarmOS TUI v1.23.4

This release establishes the canonical SwarmOS TUI release channel with
verified native binaries for Linux, macOS, and Windows.

## Highlights

- Publishes immutable, versioned TUI releases from the private monorepo to the
  public `Swarm-Code/swarm-releases` distribution repository.
- Publishes native Linux amd64/arm64, macOS amd64/arm64, and Windows amd64
  executables.
- Adds mandatory SHA-256 verification for updater downloads.
- Includes an SPDX JSON SBOM plus GitHub Actions OIDC/Sigstore-signed SLSA
  provenance and SBOM bundles for offline verification.
- Exercises attestation signing and offline verification during pull-request
  validation, before the immutable release tag is created.

## Verification

Every executable is built on its native GitHub-hosted runner, executes its own
`--version` check before publication, and is accompanied by a platform-specific
SHA-256 file. The release also includes a combined `checksums.txt` manifest,
the exact embedded Go module dependency inventory, an SPDX JSON SBOM, and
public offline-verifiable provenance and SBOM bundles.

Source release tag: `tui/v1.23.4`
